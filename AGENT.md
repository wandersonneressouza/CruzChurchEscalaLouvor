# AGENTS
Este é um projeto web feito em React com Vite e comunicação com API externa.

## Diretório docs e contexto
- Sempre leia os arquivos da pasta `docs` antes de tomar decisões
- O diretório docs contém todo o contexto desse projeto
- Sempre leia o arquivo `docs/funcionalidades_ministerio.md` E `docs/plano_implementacao_ministerio.md` para entender do que se trata o meu projeto
- Imagens de referenias para desenvolvimento das telas estão em `img/`
- **IMPORTANTE:** Sempre leia e siga as regras do arquivo `docs/arquitetura.md` antes de criar novos códigos

## Backlogs
- Você deve sempre ler o arquivo `docs/backlog.md`
- Antes de implementar novas features, verifique o arquivo `docs/backlog.md` e verifique se já foi implementado e como ele funciona
- Após implementar uma nova feature, adicione ela em `docs/backlog.md`
    - O arquivo de backlog não é escrito por humanos, apenas por você e outras IAs
    - Sempre escreva da forma que é melhor para você mesmo e outras IAs entender o contexto
